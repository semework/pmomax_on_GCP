# HFS SaS Awards 2026 Submission Package for PMOMax

Updated May 19, 2026.

This folder contains a submission-ready package for the HFS Services-as-Software Awards 2026.

## Current HFS requirements checked

- Submissions close June 30, 2026.
- Entry is free.
- The form asks for one selected category.
- The live form is five steps: organization details, award category, three written answers plus optional video, confirmation/consent, and submission confirmation.
- The required written submission has three sections:
  - Why this matters
  - What you built or transformed
  - So what
- Optional: one-minute executive video.
- HFS judging criteria include AI-driven delivery, agentic adaptability, outcome orientation, scalable architecture, and proven enterprise success.
- The HFS page contains an older footer line saying submissions close December 15, 2025, but the current 2026 awards content and form state June 30, 2026.

## Recommended category

Primary:

`Best 'Software Eating Services'`

Secondary only if submitting a separate second entry:

`Best Startup / Emerging Firm`

## Important editing note

The package is intentionally written without unsupported ROI, adoption, or customer outcome claims. If real customer or pilot metrics become available before submission, add them to the "So what" answer. Otherwise submit the current version as product readiness, Marketplace availability, deployment validation, and operating-model evidence.
