# Supporting File 1: PMOMax overview

Prepared for the HFS Services-as-Software Awards 2026. Updated May 19, 2026.

## Product

PMOMax is an AI-assisted project initiation platform from Katalyst Street.

## What it does

It turns raw project material into a structured PID workspace with linked planning, governance, compliance, risk, budget, stakeholder, and exportable outputs.

## Confirmed capabilities

- paste or upload source project material
- load full demo data
- guided create mode
- structured PID sections
- objectives and KPIs
- scope, constraints, assumptions, and dependencies
- schedule and Gantt view
- people, resources, and budget
- risks, issues, and communications
- governance and compliance sections
- AI assistant working against live project context
- help and user guide
- export to Word, PDF, structured data files, and packaged outputs
- public Google Cloud Marketplace listing
- verified Marketplace deployment readiness
- Marketplace usage-based billing validation

## Why it matters

Many teams begin projects with fragmented material and inconsistent templates. PMOMax gives them one controlled surface to structure that work before execution begins.
