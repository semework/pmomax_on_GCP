# PMOMax Corrected Materials Pack

This folder is the corrected source-of-truth pack for PMOMax external, internal, Marketplace, help, guide, and promotional language.

Use these files instead of older promo decks, reports, voiceover drafts, copied writeups, or backup documents when describing current PMOMax capabilities.

## What Changed

Unsupported or overstated claims were removed or softened:

- No claim that PMOMax currently implements Agent-to-Agent (A2A) runtime protocol integration.
- No claim that PMOMax currently provides native Google Docs or Google Sheets add-ins.
- No claim that PMOMax creates immutable audit logs by default.
- No claim that PMOMax centrally stores customer audit logs.
- No claim that PMOMax provides a hard policy engine where agents cannot bypass rules.
- No claim that PMOMax runs on Anthos specifically.
- Governance and compliance capabilities are described as AI-assisted review and gap surfacing, not as separate fully autonomous enforcement agents.

## Files

- `source-of-truth.md`: verified product and deployment facts.
- `claim-correction-log.md`: false or risky claims and corrected wording.
- `whitepaper-corrected.md`: long-form corrected whitepaper.
- `short-overview.md`: short general-purpose overview.
- `solution-brief.md`: customer-facing product brief.
- `promo-copy.md`: short website, listing, and email copy.
- `user-guide-corrected.md`: user guide aligned with the current app and deployment model.
- `technical-architecture.md`: technical architecture and Marketplace deployment summary.
- `marketplace-and-audit-faq.md`: Marketplace, tenant safety, and AI audit traceability FAQ.
- `video-script-corrected.md`: corrected narration script.
- `email-note-approved-materials.md`: short email note asking collaborators to use approved materials.
- `word-doc-replacements.md`: corrected source text for regenerated Word documents.
- `presentation-deck-outline-corrected.md`: corrected source text for new PowerPoint decks.
- `materials-inventory.md`: inventory and replacement map for older/current materials.
