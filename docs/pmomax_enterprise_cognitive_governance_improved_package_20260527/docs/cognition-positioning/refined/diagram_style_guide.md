# Diagram Style Guide

## Design goal

All diagrams should look suitable for enterprise sales decks, Google/IBM presentations, whitepapers, and investor discussions.

## Visual rules

- Use light background.
- Use dark slate text.
- Use blue as the primary accent.
- Use teal for accountability/human review.
- Use amber for risk/escalation.
- Use purple sparingly for AI/model layers.
- Use rounded rectangles.
- Keep text short.
- Use strong titles and subtitles.
- Leave generous whitespace.
- Avoid clutter and dense Mermaid-style diagrams.

## Recommended diagram categories

1. Governance stack.
2. Human-agent governance loop.
3. Three Questions model.
4. Boundary schema flow.
5. Cognitive trace protocol.
6. Multi-agent governance architecture.
7. Regulated AI decision lifecycle.
8. PMOMax upstream control artifact.

## Export formats

- PNG for decks and email.
- SVG for web, Figma, and vector editing.
- Mermaid source for technical docs.
