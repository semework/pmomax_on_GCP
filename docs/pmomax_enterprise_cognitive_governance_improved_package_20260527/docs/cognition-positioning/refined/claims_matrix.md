# Claims Matrix: Implemented, Partial, Roadmap, Avoid

## Implementation-backed claims

| Claim | Safe wording |
|---|---|
| PMOMax supports AI-assisted PID creation | PMOMax helps teams create structured Project Initiation Documents from project context. |
| PMOMax structures governance information | PMOMax organizes scope, objectives, risks, approvals, stakeholders, dependencies, and decisions into reviewable sections. |
| PMOMax supports exportable governance artifacts | PMOMax supports export-oriented workflows for governance records and project initiation artifacts. |
| PMOMax has audit metadata concepts | PMOMax supports configurable AI audit metadata and trace concepts that can feed enterprise review workflows. |
| PMOMax supports Google Cloud Marketplace packaging | PMOMax has Marketplace-oriented deployment and packaging assets. |

## Partially supported claims

| Claim | Safer version |
|---|---|
| PMOMax governs AI decisions | PMOMax helps structure governance context around AI-enabled decisions. |
| PMOMax enforces policy-constrained reasoning | PMOMax can help surface policy, compliance, and risk considerations during initiation and review. |
| PMOMax provides cognitive auditability | PMOMax supports structured trace metadata and exportable review artifacts that can contribute to auditability. |
| PMOMax supports regulated AI workflows | PMOMax can support regulated-workflow documentation and review readiness. |

## Roadmap-only claims

| Claim | Status |
|---|---|
| Full multi-agent governance runtime | Roadmap unless implemented and demonstrable. |
| Immutable audit ledger | Roadmap unless WORM/signed/ledger-backed retention exists. |
| Formal cognitive governance protocol API | Proposed specification, not product contract yet. |
| Autonomous escalation engine | Roadmap unless visible in workflow/UI. |
| A2A interoperability | Roadmap unless implemented and validated. |

## Claims to avoid

- PMOMax guarantees compliance.
- PMOMax certifies ISO/IEC 42001 readiness.
- PMOMax prevents all policy violations.
- PMOMax replaces legal, compliance, security, or audit teams.
- PMOMax captures full model reasoning.
- PMOMax is a complete autonomous cognition operating system today.
- PMOMax controls enterprise machine cognition end-to-end.
