# Required Demo Workflow

## Purpose

The package needs one concrete workflow demo to make Enterprise Cognitive Governance operational rather than conceptual.

## Recommended demo: AI-enabled clinical operations project

Use case: a healthcare organization wants to deploy an AI assistant for patient intake triage support.

## Demo sequence

1. User enters initiative description.
2. PMOMax generates a structured PID.
3. PMOMax identifies sensitive data boundaries.
4. PMOMax proposes allowed and prohibited AI actions.
5. PMOMax creates risks and mitigations.
6. PMOMax flags escalation triggers.
7. PMOMax assigns human owner and reviewer.
8. PMOMax generates an audit metadata panel.
9. User approves/rejects recommendations.
10. PMOMax exports governance artifact.

## Minimum visible UI elements

- Governance Boundary section.
- Decision Authority section.
- Escalation Required indicator.
- Human Owner field.
- Audit Metadata panel.
- Export Governance Record button.

## Export artifact should include

- project objective,
- AI scope,
- prohibited actions,
- data sensitivity,
- risks,
- mitigations,
- reviewer,
- approval state,
- generated timestamp,
- model/provider metadata if available.

## Why this matters

This demo turns the cognition narrative into a product story. It allows Google, IBM, investors, and enterprise buyers to see PMOMax as a practical governance system, not just a whitepaper concept.
